# kbl

ЯП с C-подобным синтаксисом для автоматизации: управление
клавиатурой, мышью, окнами, процессами и буфером обмена. Один exe, без зависимостей,
только WinAPI.

```
kbl.exe script.kbl
```

## Сборка

Нужен Visual Studio с рабочей нагрузкой «Разработка классических приложений на C++».

```
build.bat
```

Готовый файл: `build\kbl.exe`. Скрипт сборки сам находит `vcvars64.bat` через vswhere.

## Запуск

```
build\kbl.exe examples\hello.kbl
build\kbl.exe --check script.kbl      
build\kbl.exe --no-safety script.kbl  
build\kbl.exe --version
build\kbl.exe --help
```

**Аварийная остановка: Ctrl+Alt+Esc.** Работает во время выполнения любого скрипта.

## Привязка расширения .kbl

```
install-assoc.bat     :: HKCU, без прав администратора и без установщика
uninstall-assoc.bat   :: удалить связь
```

После этого `.kbl` открывается двойным кликом. Файл можно и просто перетащить на `kbl.exe`.

## Язык

Синтаксис в стиле C: блоки `{}`, `;` в конце операторов, комментарии `//` и `/* */`.
Типы динамические, объявление с типом или без него.

```kbl
// переменные
int a = 10;
double d = 1.5;
string s = "текст";
bool ok = true;
var x = 42;

// арифметика, сравнения, логика
int sum = a + 5 * 2;        // int / int = int (10 / 3 == 3)
double r = a / 4.0;         // 2.5
bool b = (a > 5) && ok;
a += 3; a++; --a; x *= 2;

// условия
if (a > 10) {
    println("больше");
} else if (a == 10) {
    println("ровно");
} else {
    println("меньше");
}

// циклы
for (int i = 0; i < 10; i++) {
    if (i == 3) continue;
    if (i == 8) break;
    println(i);
}

int n = 0;
while (n < 5) {
    n++;
}

// функции; вызовы разрешаются после разбора всего файла,
// поэтому функция может быть объявлена ниже места вызова
func add(int x, int y) {
    return x + y;
}

int mul2(int v) {
    return v * 2;
}

println(add(2, 3));
```

Строки в UTF-8, поддерживаются escapes: `\n \r \t \\ \" \' \0 \xNN \uXXXX`.
Склеивание строк и чисел через `+`: `"a = " + 5` → `a = 5`.

Файл должен быть в кодировке UTF-8 (BOM допускается).

## Встроенные функции

### Вывод и время

| Функция | Описание |
|---|---|
| `print(a, b, ...)` | вывести значения через пробел, без перевода строки |
| `println(a, b, ...)` | то же, с переводом строки |
| `sleep(ms)` | пауза в миллисекундах (поддерживаются дробные) |
| `time_ms()` | миллисекунды с момента загрузки системы |
| `time_s()` | секунды, число с плавающей точкой |

### Клавиатура

| Функция | Описание |
|---|---|
| `type("текст")` | напечатать текст (Unicode, не зависит от раскладки) |
| `type("текст", 50)` | то же с паузой 50 мс между символами |
| `key_press("ctrl+shift+a")` | нажать и отпустить комбинацию |
| `key_down("shift")` | зажать |
| `key_up("shift")` | отпустить |
| `key_state("ctrl+alt+k")` | `true`, если все клавиши зажаты |

Имена клавиш: `a`..`z`, `0`..`9`, `f1`..`f24`, `enter`, `esc`, `tab`, `space`,
`backspace`, `delete`, `insert`, `home`, `end`, `pageup`, `pagedown`, `up`, `down`,
`left`, `right`, `shift`, `ctrl`, `alt`, `win`, `capslock`, `numlock`, `printscreen`,
`pause`, `apps`, `minus`, `plus`, `equal`, `comma`, `period`, `slash`, `backslash`,
`semicolon`, `quote`, `grave`, `lbracket`, `rbracket`.

### Мышь

| Функция | Описание |
|---|---|
| `mouse_move(x, y)` | переместить курсор |
| `mouse_move(x, y, 300)` | плавно за 300 мс |
| `mouse_move_rel(dx, dy)` | сместить относительно текущей позиции |
| `mouse_x()`, `mouse_y()` | текущие координаты |
| `mouse_click()` | левый клик |
| `mouse_click("right")` | клик правой кнопкой |
| `mouse_click("left", x, y)` | клик в точке |
| `mouse_down("left")`, `mouse_up("left")` | зажать/отпустить кнопку |
| `mouse_wheel(3)` | колесо, в «щелчках» (плюс — вверх) |
| `mouse_wheel_h(-2)` | горизонтальное колесо |
| `screen_width()`, `screen_height()` | размер основного экрана |
| `pixel_color(x, y)` | цвет точки как `0xRRGGBB`, `-1` при ошибке |

Кнопки: `left`, `right`, `middle`, `x1`, `x2`.

### Окна

| Функция | Описание |
|---|---|
| `window_find("часть заголовка")` | дескриптор окна или `0` |
| `window_find("точный заголовок", true)` | точное совпадение |
| `window_wait("заголовок", 5000)` | ждать появления окна, мс |
| `window_active()` | дескриптор активного окна |
| `window_activate(h)` | вывести окно на передний план, `true` при успехе |
| `window_title(h)` | заголовок окна |
| `window_close(h)` | отправить окну `WM_CLOSE` |
| `window_exists(h)` | существует ли окно |

Поиск по заголовку **не учитывает регистр** и по умолчанию ищет подстроку.
Будьте точны: `window_wait("Notepad")` может найти уже открытый Блокнот с вашим
документом, и скрипт начнёт печатать в него.

### Процессы и буфер обмена

| Функция | Описание |
|---|---|
| `run("cmd /c dir")` | выполнить и дождаться, вернуть код выхода |
| `start("notepad")` | запустить и не ждать, вернуть PID |
| `kill(pid)` | завершить процесс, `true` при успехе |
| `clip_get()` | прочитать текст из буфера обмена |
| `clip_set("текст")` | записать текст в буфер обмена |
| `msgbox("заголовок", "текст")` | окно с сообщением |
| `input("подсказка")` | прочитать строку из stdin |

### Строки, числа, прочее

| Функция | Описание |
|---|---|
| `to_str(v)`, `to_int(v)`, `to_float(v)`, `to_bool(v)` | преобразование типов |
| `typeof(v)` | `"int"`, `"float"`, `"bool"`, `"string"`, `"null"` |
| `len(s)` | длина строки в символах |
| `upper(s)`, `lower(s)`, `trim(s)` | регистр и обрезка пробелов |
| `replace(s, "a", "b")` | заменить все вхождения |
| `contains(s, "x")` | содержит ли подстроку |
| `substr(s, start, len)` | подстрока в символах |
| `ord(s)`, `chr(n)` | код первого символа / символ по коду |
| `random(1, 10)` | целое в диапазоне включительно |
| `random_float()`, `random_float(0, 1)` | дробное число |
| `exit(0)` | завершить скрипт с кодом |

## Пример

```kbl
// Открыть «Выполнить», запустить Блокнот, напечатать текст
key_press("win+r");
sleep(700);
type("notepad");
key_press("enter");
sleep(1200);
type("Привет из kbl!\n");
```

Больше примеров в папке `examples`.

## Ограничения

* Только Windows.
* Синтетический ввод не доходит до окон, запущенных **от администратора**, если
  сам `kbl.exe` запущен без прав администратора (UIPI).
* Secure desktop (UAC, Ctrl+Alt+Del) не принимает синтетический ввод.
* Ввод попадает в **активное** окно. Если фокус перехватит другая программа,
  текст уйдёт туда. Проверяйте `window_activate`.
* Некоторые игры и защищённые приложения игнорируют `SendInput`.
* Нет массивов, структур и горячих клавиш-обработчиков; скрипт линейный.
